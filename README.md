### 👋 Hi, I'm Babafemi

I'm a **Senior Software Engineer** in **Columbus, OH** who builds **React Native and React/Next.js** apps end to end, mostly in **healthcare and enterprise**. I've spent 8+ years taking products from Figma to App Store and keeping them reliable once they're live.

Most recently at **Telus Digital (formerly WillowTree)**. Before that I built BLE-connected medical apps at **Rhaeos**, and delivered enterprise mobile and web apps for clients like **ExxonMobil, Pool Corp, and Oceaneering**.

### 🏆 Highlights

| | |
|---|---|
| 🧩 **Shared component library** | Architected a React Native design system from Figma, adopted by **10+ production apps across 10 teams** |
| 🤖 **RAG document assistant** | Built the React Native + Electron chat UI and source viewer, cutting review time from **hours to under 2 minutes per 1,000+ pages** |
| 📶 **Offline-first architecture** | Encrypted SQLite, biometric auth, and centralized state to **prevent data loss** during network drops |
| 🩺 **HIPAA-grade medical apps** | Custom **Swift native module** bridging medical hardware over BLE Secure Connections to React Native |
| 📈 **Observability** | Grafana + App Insights dashboards that cut incident triage from **~2 hours to under 30 minutes** |
| 🚀 **Release automation** | Fastlane + Azure DevOps pipelines for TestFlight and Intune, with certificates managed in Key Vault |
